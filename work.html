A snapshot of outcomes we deliver

Three projects that show the range: a revenue-critical quoting platform, a finance workflow fix, and machine learning running on a microcontroller. More available on request.

Case studies

01 Logistics & InsurTech

Logistics quote engine

.NET · React · Azure

Multi-carrier insurance quoting platform with finance integrations and role-based access.

The build

A quoting engine that reaches multiple carriers, reconciles the responses, and hands clean figures to the finance systems downstream — with permissions that match how the business is actually structured.

The result

Faster quotes and fewer errors. Quoting stopped being the bottleneck in the sales cycle.

  • .NET
  • React
  • Azure
  • Role-based access
  • Finance integrations

02 Finance operations

Account ledger export

.NET · SQL Server

Excel export with a custom schema and confirmation steps, built around how the finance team already works.

The build

A ledger export matching the exact schema finance needed, with explicit confirmation before anything leaves the system — so exports are deliberate, repeatable and traceable.

The result

Improved finance workflows and audit trails. Reconciliation stopped depending on hand-built spreadsheets.

  • .NET
  • SQL Server
  • Custom schema
  • Audit trails

03 Embedded & ML

Voice-driven TinyML device

TinyML · Embedded

Microcontroller solution recognising voice commands to trigger actions — lightweight ML at the edge.

The build

A model small enough to run on a microcontroller, listening for a fixed command set and driving actions directly on the device.

The result

Inference happens on-device — no cloud round-trip, and no audio leaving the hardware.

  • TinyML
  • Embedded
  • On-device inference
